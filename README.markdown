Gigahorse
==========

Gigahorse is an HTTP client for Scala with multiple backend support.
Gigahorse can wrap [Apache HttpComponents HttpClient][apachehttp],
[Async Http Client 2.12.x][ahc],
[Square OkHttp 3.x][okhttp],
or [Pekko HTTP][pekkohttp] underneath.

For more info, see [the Gigahorse docs][docs].
